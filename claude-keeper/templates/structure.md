# .claude/ に何を置くか

置き場所は 4 つある。**選び方を間違えると、置いたものが一度も使われない。**

| 置き場所 | 何か | 呼ばれ方 | 会話の記憶 |
|---|---|---|---|
| `skills/` | 知識・規約 | Claude が description を読んで自分で選ぶ | 引き継ぐ |
| `commands/` | 手順 | 人が `/名前` と打つ | 引き継ぐ |
| `agents/` | 立場 | Claude が仕事を渡す / 人が指名する | **切れる** |
| `settings.json` の hooks | 機械の反射 | 決めた瞬間に必ず走る | 関係ない |

## 選び分け

| やりたいこと | 置き場所 | なぜ |
|---|---|---|
| 毎回この規約を守らせたい | **skill** | 呼ばれ方を人が覚えなくていい |
| 一連の手順を、人の合図で走らせたい | **command** | 引数が取れて、順番を書ける |
| 自分が書いたものを疑わせたい | **agent** | **会話の記憶が切れる。これが本体** |
| 大量に読ませて、結論だけ受け取りたい | **agent** | 読んだ中身が本体の文脈を埋めない |
| 必ず・例外なく起きてほしい | **hook** | Claude の判断を通さない |
| 忘れたころに定期で走ってほしい | **routine** | セッションが無くても動く |

**迷ったら skill。** command は人が覚えていないと呼ばれず、agent は本体が
渡そうと思わないと動かない。skill は description が合えば勝手に効く。

## agent を置く判断

agent の値打ちは並列化ではなく、**文脈が切れること**。だから置くのは、

- 本体が肩入れしている仕事 (自分の実装のレビュー、自分が書いた docs の検証)
- 立場を固定したい仕事 (利用者として見る、金を払う側として見る)
- 読む量が多く、結論だけ欲しい仕事 (全ファイルを見て 5 行返す)

置かなくていいのは、

- 本体がそのまま続ければいい仕事 (直す・書く)
- 会話の流れを知らないと判断できない仕事。**agent には流れが伝わらない**

### agent に書くこと

1. **立場** — 誰として読むか。「開発者として」は立場ではない
2. **見るもの** — パスかコマンドで具体的に。「全体」と書かない
3. **証拠の作り方** — 何をもって主張とするか (skill `flat-view`)
4. **出力の型** — 何行で、どの順で返すか。**ここを書かないと感想文になる**
5. **やらないこと** — 直さない / 全部を挙げない / 好みを言わない

`tools:` は必要なものだけ。読む役に Write を渡すと、頼んでいないのに直し始める。

## command を置く判断

command は「人が、いま、これをやれ」と言うもの。**手順が 2 段階以上あるとき**に
値打ちが出る (1 段階なら口で頼めば済む)。

- 引数の解釈を最初に書く。`$ARGUMENTS` が何を意味するか
- 途中で承認を取る箇所を明示する。**書き換えるものは必ず先に見せる**
- 最後に「報告に何を含めるか」を書く。ここが抜けると出力が毎回変わる

## skill を置く判断

skill は「読めば作業が変わる」もの。**description に、いつ読むかを書く**
(何が書いてあるかだけ書くと、必要なときに選ばれない)。

- 規約・禁止事項・書式は skill 向き
- 手順は command 向き。skill に手順を書くと、読まれても実行されない
- 長い参考資料は `references/` に分け、SKILL.md からは指すだけにする

## hook を置く判断

hook は Claude の判断を通さずに走る。**間違えると邪魔しかしない。**

- 止める hook (`PreToolUse` の差し戻し) は、**壊れることが確実な操作**だけ
- 知らせる hook (`Stop`) は、**セッションに一度だけ**。同じことを繰り返さない
- 失敗しても黙って諦める。フックの都合でセッションを止めない

claude-keeper は既にセッションの頭で 1 度だけ喋る。**同じことを二重に言わない** —
プロジェクト側の hook は、それが見ていないものだけを見る。

## 置いたものが増えすぎたら

`.claude/` は増える一方になりやすい。**半年使われていない command は消す。**
役も同じで、一度も呼ばれていない agent は、要らなかったのではなく
**呼ばれ方が分からなかった**。消すか、command から名指しで呼ぶ。
