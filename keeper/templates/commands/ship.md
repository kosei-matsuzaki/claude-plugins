**コミットになる前の差分**を片づける。docs も、コードの形も、それぞれ別の役が
見ているが、**まだコミットになっていない仕事**は誰も見ていない。

## 1. 差分を取る

```bash
git status --short
git diff HEAD --stat
```

`--since <ref>` があれば `git diff <ref>` を起点にする。
差分が無ければ、ここで終わる(何もしない)。

## 2. 読ませる

`.claude/agents/reviewer.md` へ、**差分の起点だけ**を渡して投げる。
**要約して渡さない** — 要約した時点で、自分が重要だと思ったものしか見られない。

## 3. 秘密を確かめる

これだけは agent 任せにせず、**必ず自分でも見る。**

```bash
git diff HEAD | grep -nEi '(api[_-]?key|secret|token|password|BEGIN [A-Z ]*PRIVATE KEY)'
```

1 件でも出たら、そこで止めて報告する。**コミットしない。**


**通らないままコミットの話をしない。**

## 5. 直す

reviewer の指摘を 3 つに分ける。

| 仕分け | どうするか |
|---|---|
| **壊れる** | いま直す。直してから次へ |
| 残骸(デバッグ出力・コメントアウト・使わない import) | いま消す |
| 好み・構造 | 直さない。`/code` に回す |

**壊れるものを直したら、その差分をもう一度見る。**直しが新しい残骸を作る。

## 6. コミットの切り方

1 コミット = 1 つの目的。**混ざっていたら分ける。**

```
1) <パス群>   <何をしたか>
2) <パス群>   <何をしたか>
```

**一覧を見せて承認を取ってから**コミットする(`$ARGUMENTS` に `--commit` が
あっても、切り方は必ず見せる)。`--commit` が無ければ、切り方を出すだけで止まる。

メッセージは**何をしたか**を書く。「fix」「update」「wip」で終わらせない。
